# 小票手机端

静态网页，通过口令连接 AutoReceipt 的 Supabase API。

- 同一页上传照片、按日期浏览小票、进行对话。
- 每张小票可修改日期，支持 `2026-10-08`、`20261008`、`10-8` 或日历选择。
- 删除需要确认，只删除项目库中的单张记录，保留同页其他小票和电脑中的 PDF。
- 回答过程中点「停止」取消请求，之后可以重新提问；键盘也支持 Esc。
- 手机修改和删除会在 Mac 下次同步时应用；需使用支持库内变更同步的新版 Mac 应用。

部署使用 GitHub Pages：`main` 分支、根目录。无需构建。更新后刷新网页；主屏幕快捷方式仍使用同一个地址。

后端位于 `TheRookieGit/auto-receipt`，需部署 `0002_library_editing.sql` 和更新后的 `api` 云函数。

## 检查

